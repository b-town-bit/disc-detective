# Security

If you find a security problem in Disc Detective, please report it privately: open the
repository's **Security** tab and choose **Report a vulnerability**. Please don't open a
public issue for it.

Things worth reporting include the app running or installing something it shouldn't, files
being read or written outside where it should, or data it downloads (TheDiscDB, IMDb, TVmaze,
TMDB) being able to make it misbehave.

Fixes go into the latest release only.
